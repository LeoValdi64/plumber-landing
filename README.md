# ProFlow Plumbing Landing Page

🔗 **Live:** [plumber-landing-three.vercel.app](https://plumber-landing-three.vercel.app)

Professional landing page for a plumbing company, designed to convert visitors into customers with strong CTAs and trust-building elements.

## Features

- 🚨 **24/7 Emergency Banner** - Prominent emergency service messaging
- 📞 **Sticky Header** - Phone number always visible for easy contact
- 🔧 **Services Grid** - 6 detailed service cards with descriptions
- ⭐ **Trust Badges** - Licensed, Insured, 5-Star Rated indicators
- 📍 **Service Areas** - Interactive service area display
- 💬 **Testimonials** - Customer reviews with ratings
- 📝 **Contact Form** - Service type dropdown, complete lead capture
- 📱 **Fully Responsive** - Mobile-first design
- 🎨 **Professional Design** - Blue/white color scheme typical for plumbing industry

## Sections

1. Hero with dual CTAs (Call Now / Get Quote)
2. Services Grid (Drain Cleaning, Water Heater, Leak Detection, etc.)
3. Why Choose Us (4 trust factors)
4. Service Areas (Seattle metro area)
5. Customer Testimonials
6. Emergency Contact Banner
7. Contact Form with service dropdown
8. Footer with business info

## Stack

- **Framework:** Next.js 16.1.6 (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Deploy:** Vercel

## SEO

- Complete meta tags for local plumbing business
- Open Graph tags for social sharing
- Semantic HTML structure
